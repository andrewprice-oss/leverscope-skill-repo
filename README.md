# LeverScope skill: system dynamics models from a conversation

Ask an AI assistant how something grows, spreads, fills up, runs out or swings back and forth over time. With this skill, the assistant builds a small **stock-and-flow model** and gives you a link that opens it in **[LeverScope](https://leverscope.com)**, a free system dynamics tool that runs in the browser (English and German). There you see the map, move the sliders, compare scenarios and find the levers that matter.

- **No server, no account:** the model travels inside the link (after `#`), so nothing is uploaded.
- **Works with Claude, ChatGPT, Copilot, Gemini** and any assistant that can read a web page or a file.
- **Checked before it is handed over:** the bundled script checks names, flows, equations and references, then prints the link.

## Install

**Claude:** download this repository as a ZIP, or use the ready-made [leverscope-skill.zip](https://leverscope.com/ai/leverscope-skill.zip). Add the `leverscope` folder as a skill in Claude's settings. Claude then uses it by itself when a question is about change over time.

**Claude Code / Agent SDK:** copy the `leverscope` folder into your skills directory (for example `~/.claude/skills/leverscope`).

**Any other assistant:** paste this into the chat, followed by your question:

```
Read https://leverscope.com/for-ai.html and follow it. Build a LeverScope model for my question,
give me the link that opens it, and explain in a few sentences what to try with the sliders.
```

## Contents

| Path | What it is |
|---|---|
| `leverscope/SKILL.md` | The instructions: model format, functions, common patterns (capacity and overflow, delays, ordering, queues, seasons), hand-over |
| `leverscope/scripts/leverscope_link.py` | Checks a model JSON and prints the link (`python3 leverscope_link.py model.json`) |
| `schema/leverscope-model.schema.json` | The model format as JSON Schema (also at https://leverscope.com/schema/leverscope-model.schema.json) |
| `examples/` | Example models written with the skill |

## Model format in one minute

```json
{
  "name": "Bathtub",
  "sim": { "start": 0, "stop": 30, "dt": 0.25, "unit": "minutes" },
  "elements": [
    { "type": "stock", "name": "Water", "eq": 20, "units": "litres" },
    { "type": "flow", "name": "Tap", "from": null, "to": "Water", "eq": "Tap_Setting" },
    { "type": "flow", "name": "Drain", "from": "Water", "to": null, "eq": "Water*Drain_Rate" },
    { "type": "converter", "name": "Tap_Setting", "eq": 8, "slider": { "min": 0, "max": 20, "kind": "decision" } },
    { "type": "converter", "name": "Drain_Rate", "eq": 0.1, "slider": true }
  ]
}
```

Link forms: `https://leverscope.com/app/#model=` + raw-DEFLATE + base64url (the script makes this), `https://leverscope.com/app/#json=` + URL-encoded JSON for small models, or paste at `https://leverscope.com/app/#paste`. Full guide: https://leverscope.com/for-ai.html
